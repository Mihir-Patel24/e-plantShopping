# Paradise Nursery

## Project Name
**Paradise Nursery — e-plantShopping**

Paradise Nursery is a React-based online houseplant shopping application. Users can explore plants by category, add plants to their cart, adjust quantities, remove items, and view their order total.

## Features
- Landing page with “Welcome to Paradise Nursery” and a Get Started button
- About Us company information
- Three categories with six plants per category
- Product images, names, descriptions, and prices
- Redux Toolkit cart with addItem, removeItem, and updateQuantity reducers
- Dynamic cart quantity indicator
- Cart line totals, order total, checkout message, and continue-shopping button

## Run locally
Run `npm install` followed by `npm run dev`.
